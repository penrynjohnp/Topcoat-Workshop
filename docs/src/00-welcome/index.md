# Welcome

Documentation for the Topcoat Workshop: hands-on labs for learning [Topcoat](https://github.com/tokio-rs/topcoat), the server-rendered full-stack web framework from tokio-rs.

Read **Concepts** alongside the labs, use **Reference** while you build, and check the **Appendix** if you're coming from only one side of the Rust/web divide.

Start with [Setup](setup.md), then [Lab 01](../02-labs/lab-01.md).
